# Merge PDF API

Use the PDF.co merge endpoint to combine multiple PDF files into one output document.

**Endpoint:** `POST https://api.pdf.co/v1/pdf/merge`

## Start here

New to this endpoint? Work through [Merge PDF files](./merge-pdfs.md) to send your first request with `curl` and read the response.

## Recommended reading order

1. [Merge PDF files](./merge-pdfs.md): Complete a first merge.
2. [Merge PDF API reference](./merge-reference.md): Look up fields while building.
3. [Understand how credits are charged](./credits.md): Plan and monitor usage.
4. [Fix errors in file merge actions](./troubleshooting.md): What you can do when something breaks.

## Prerequisites

- A PDF.co account and API key.
- Basic REST and `curl` familiarity.
- PDF file URLs that PDF.co can access over HTTPS.

Pass your API key in the `x-api-key` header. Read the [PDF.co API documentation](https://developer.pdf.co/api) for authentication details.
